# Projects

実行ごとの成果物を `run-YYYYMMDD-HHMM` 単位で保存する。

例:
- `blueprint/project_blueprint.json`
- `variables/E##_variables.json`
- `script/E##_script.md`
- `voicevox_text/E##_voicevox_text.json`
- `voicevox_text/E##_voicevox.txt`
- `dict_candidates/E##_dict_candidates.csv`
- `voicevox_project/E##_voicevox_import.json`
- `voicevox_project/E##.vvproj`
- `voicevox_project/E##_project_meta.json`
- `audio/E##.wav`
- `audio/E##.mp3`（既定）
- `audio/manifest.json`
